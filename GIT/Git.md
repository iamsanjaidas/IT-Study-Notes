# **What is Git?**
Git = Version Control System (VCS).
Its job is to track changes to files.

Imagine you have:

```
Linux.md
```

Monday:

```
Linux is an operating system.
```

Tuesday you add:

```
Linux is an operating system.

It uses the Linux kernel.
```

Git can remember both versions.

You can think:

```
Version 1
   ↓
Version 2
   ↓
Version 3
   ↓
Version 4
```

This is called **version control**.
